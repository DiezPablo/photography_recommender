# 0023 — De las rutas, solo el acceso a cada spot
Fecha: 2026-11-15 · Estado: vigente (sustituye a 0019)
Contexto: las rutas de senderismo (8500 fichas, GPX, logística de OSM) estaban aparcadas (0019). Son de planificar
la salida, no de decidir adónde ir; pero cómo se llega a un spot sí ayuda a decidir.
Decisión: no se trae el catálogo de rutas. Se aprovecha la logística de OSM de `photo_recommender` para dar, en
cada spot, el aparcamiento más cercano y cuánto se tarda andando (spec 023).
Consecuencias: sin `/rutas`, GPX ni fichas de ruta. La decisión 0010 (fuentes abiertas) vale para el acceso.
