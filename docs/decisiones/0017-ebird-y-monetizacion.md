# 0017 — Sin monetización; eBird, a fondo
Fecha: 2026-11-13 · Estado: vigente
Contexto: los datos de la API de eBird son de uso no comercial. Pablo decide que Rasante no se va a monetizar.
Decisión: Rasante es y seguirá siendo de uso personal, sin fines comerciales. La API de eBird se usa con toda
la información que dé (recientes, rarezas, puntos, listas, estadísticas), citando la fuente.
Consecuencias: la licencia ya no limita qué fuente se usa; sí obliga a atribuir (`docs/datos/fuentes.md`,
`/fuentes`) y a respetar los límites de cada API. Qué más sacar de eBird: spec 021.
